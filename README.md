# یکی‌یدونم — سایت نامه‌های عاشقانه

سایتی با ۱۲۰ نامه‌ی عاشقانه + ۵ نامه‌ی پنهان، از امیرعلی برای نازنین.

## فایل‌ها
- `index.html` — ساختار صفحه
- `style.css` — استایل (تم آبی‌سرمه‌ای/مشکی/زرشکی)
- `letters.js` — متن ۱۲۰ نامه + نامه‌های پنهان (اینجا رو ویرایش کن)
- `script.js` — منطق سایت (قفل روزانه، انیمیشن پاکت، ایستر اگ‌ها، موسیقی)

## چطور روی GitHub Pages بذاری
1. یک ریپازیتوری جدید در گیت‌هاب بساز (مثلاً `love-letters`).
2. همه‌ی این فایل‌ها رو داخلش آپلود کن (Add file → Upload files).
3. برو به تب **Settings → Pages**.
4. زیر «Build and deployment»، Source رو روی **Deploy from a branch** بذار، برنچ `main` و پوشه‌ی `/ (root)` رو انتخاب کن و Save بزن.
5. بعد از حدود ۱ دقیقه، آدرس سایتت این شکلی می‌شه:
   `https://USERNAME.github.io/love-letters/`

## چطور متن نامه‌ها رو عوض کنی
فایل `letters.js` رو باز کن. هر نامه یک آبجکت با `id`، `title` و `text` هست.
فقط مقدار `text` (و در صورت نیاز `title`) رو با متن واقعی خودت جایگزین کن؛ بقیه‌ی سایت خودکار کار می‌کنه.

آرایه‌ی `HIDDEN_LETTERS` هم ۵ نامه‌ی پنهانه که با این کارها باز می‌شن:
1. سه بار کلیک روی نوشته‌ی «امیرعلی و نازنین» بالای صفحه‌ی اول
2. کلیک روی قلب کوچک گوشه‌ی پایین-چپ صفحه
3. تایپ کلمه‌ی «نازنین» در هر جای صفحه (با کیبورد)
4. اسکرول تا انتهای جعبه‌ی نامه‌ها
5. پنج بار کلیک روی دکمه‌ی موسیقی (گوشه‌ی پایین-راست)

## تنظیم تاریخ شروع
اولین باری که سایت باز بشه، تاریخ همون لحظه به‌عنوان «روز اول» ذخیره می‌شه (در مرورگر خود کاربر) و از فردا، هر روز یک نامه‌ی جدید باز می‌شه.
اگر می‌خوای همه‌ی نامه‌ها همون روز اول قابل‌دسترسی نباشن ولی از یک تاریخ ثابت (مثلاً سالگرد) شمارش بشه، در `script.js` تابع `getStartDate` رو ویرایش کن و به‌جای `new Date().toISOString()`، یک تاریخ ثابت مثل `"2026-01-01T00:00:00"` بگذار.

## نکته درباره‌ی داده‌ها
پیشرفت (نامه‌های خوانده‌شده) در `localStorage` مرورگر خود کاربر ذخیره می‌شه، یعنی روی هر دستگاه/مرورگر جدا حساب می‌شه و با پاک کردن کش مرورگر از بین می‌ره.
